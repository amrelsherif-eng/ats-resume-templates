## 🚀 Start in 3 Steps (no LaTeX needed)

1. **Pick** the template that matches the job you want ([see below](#-pick-your-template)).
2. **Open it in Overleaf** and click **`File` → `Make a copy`** (free account required).
3. **Replace the sample text** with your own details, or let an AI fill it for you ([prompt below](#-let-ai-fill-it-in)), then click **Recompile** and download your PDF.

> All three templates contain **fictional sample data** ("Your Name", example.com). Nothing in them is a real person's CV.

---

## 🧠 Why These Templates?

> Recruiters skim a resume in seconds, and many companies run it through an Applicant Tracking System (ATS) first. A resume that a machine cannot read, or that runs to two pages, often never reaches a person.

| Challenge | How these templates handle it |
|:---|:---|
| 📄 Resume too long | Strict one-page layout with tuned margins and spacing |
| 🤖 ATS cannot read it | Real, selectable text (`\pdfgentounicode=1`, T1 fonts), single column, no images, no text boxes, no icons |
| 🔍 Wrong things stand out | Each template orders and phrases sections for its career track |
| 🎨 Overdesigned layouts | Clean typographic hierarchy: no columns, no graphics, no noise |
| 🧩 Hard to customize | Reusable macros and labelled sections: change content without touching the layout |

### ✅ Method 1 — Copy Project (Fastest)

> **Prerequisite:** You must have a free [Overleaf account](https://www.overleaf.com/register) and be **logged in** before opening the link.

1. Open the Overleaf link of the template you want.
2. In the **top-left menu bar**, click **`File`**.
3. Select **`Make a copy`** from the dropdown.
4. A **"Copy project"** dialog will appear — rename the project if you like, then click the green **`Copy`** button.
5. Overleaf clones the full template into your account. Hit **Recompile** and start editing `resume.tex`. ✓

---

### ✅ Method 2 — Blank Project + Paste

1. Create a **New Blank Project** on [overleaf.com](https://www.overleaf.com).
2. Open `templates/<template>/resume.tex` in this repository and **copy the full raw source**.
3. **Paste** it into the `main.tex` file of your blank Overleaf project.
4. Hit **Recompile** — done. ✓

## 🤖 Let AI Fill It In

**Don't know LaTeX? You don't need to.** Copy the full contents of your chosen `resume.tex`, paste it into **Gemini**, **ChatGPT**, or **Claude**, and use this prompt:

```text
Fill this LaTeX resume template with my information below.
Rules: keep it to ONE page, keep every LaTeX command and the layout unchanged,
use only the facts I give you (do not invent numbers, tools or results),
start each bullet with an action verb, and list experience newest first.

My information:
[paste your details, old CV, or LinkedIn "About" and "Experience" here]
```

Paste the result back into Overleaf and click **Recompile**. Read every line before you send it: you are the one who will be asked about it in the interview.

## ✍️ Writing Tips That Work With Any Template

- **One idea per bullet:** action verb + what you did + the result or scope ("Configured VLANs and OSPF for a 3-site lab").
- **Only numbers you can explain.** A measured result beats an impressive guess.
- **Mirror the job post.** Use the same words for tools and skills that the posting uses, if they are true for you.
- **Newest first, one page, no photo.** Keep the PDF's text selectable and send it as PDF, not Word, unless asked.
- **One template per direction.** Applying to cloud and to mobile roles? Keep one tailored file for each.

## ✨ Key Features

- **`[01]` One-Page Layout** — Margins, spacing and section gaps are tuned so a full early-career resume fits on exactly one page.
- **`[02]` ATS-Readable PDF** — `\pdfgentounicode=1`, T1 fonts and a single-column flow produce clean, selectable text with a natural reading order. Each template's PDF was checked with text extraction before release.
- **`[03]` Clean Code Architecture** — Reusable macros (`\resumeItem`, `\resumeSubheading`, `\resumeProjectHeading`), labelled section markers, no unused packages.
- **`[04]` Easy Customization** — Content lives in clearly labelled blocks. Swap your info without touching the structure.
- **`[05]` Three Role-Focused Versions** — Same layout, different section emphasis and sample content per career track.

```
%----------- HEADING -----------        <- Name, role line, contacts
%----------- EDUCATION -----------      <- Degree, GPA, coursework
%----------- EXPERIENCE -----------     <- Newest first, 2-3 bullets each
%----------- PROJECTS -----------       <- Name | tech | GitHub link
%----------- SKILLS -----------         <- 4 grouped lines
%----------- CERTIFICATIONS -----------  <- One compact line
```

## 🖥️ Option B — Local Setup · `Advanced`

For offline editing with full IDE features (IntelliSense, SyncTeX, live PDF preview).

### Prerequisites

| Tool | Purpose |
|:---|:---|
| [VS Code](https://code.visualstudio.com/) | Editor / IDE |
| [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) | VS Code extension — build, preview, SyncTeX |
| [MiKTeX](https://miktex.org/download) | LaTeX compiler + auto package manager |
| [Strawberry Perl](https://strawberryperl.com/) | Required by the `latexmk` build tool |

### Steps

```bash
# 1. Clone the repo
git clone https://github.com/amrelsherif-eng/ats-resume-templates.git
cd ats-resume-templates

# 2. Open in VS Code
code .
```

- After cloning, open the template folder you want, e.g. `templates/network-cloud/resume.tex`, and build it
- Install **MiKTeX** → during setup, set missing packages to **"Install on-the-fly → Always"**
- Install **Strawberry Perl** → verify with `perl --version`
- Install the **LaTeX Workshop** extension in VS Code

```
Ctrl+Alt+B  →  Build PDF
Ctrl+Alt+V  →  Open PDF preview
```

> On first build, MiKTeX auto-downloads any missing packages. Requires an internet connection.

### Recommended `settings.json`

```jsonc
{
  "latex-workshop.view.pdf.viewer": "tab",
  "latex-workshop.latex.autoBuild.run": "onSave"
}
```

### Or build from a terminal

```bash
cd templates/network-cloud
latexmk -pdf resume.tex      # or: pdflatex resume.tex
```

prompt.txt
Fill this LaTeX resume template with my information below.
Rules: keep it to ONE page, keep every LaTeX command and the layout unchanged,
use only the facts I give you (do not invent numbers, tools or results),
start each bullet with an action verb, and list experience newest first.

My information:
[paste your details, old CV, or LinkedIn "About" and "Experience" here]
  1. Create a free Overleaf account.
  2. Click Open in Overleaf.
  3. Replace the text inside the { }.
  4. Click Recompile and download.
resume.tex
%----------- EXPERIENCE: newest first, 2-3 bullets each
\section{Experience}
\resumeSubheading{Finance Intern}{Jun 2026 -- Aug 2026}
  {Acme Manufacturing Co.}{Your City, Country}
\resumeItem{Prepared bank reconciliations for 2 accounts ...}

% Edit the text inside { }. Copy a line to add a bullet,
% delete it to remove one. Keep it to ONE page.
